# User Stories App

Веб-приложение для управления пользовательскими историями (User Stories) в процессе разработки программного обеспечения.

Проект разработан в рамках курсовой работы и предназначен для создания, редактирования и анализа пользовательских историй с использованием критериев INVEST.

## Возможности

- регистрация и авторизация пользователей;
- создание и управление досками пользовательских историй;
- управление пользовательскими историями;
- изменение статусов историй;
- выполнение автоматической INVEST-проверки;
- просмотр результатов предыдущих проверок;
- разграничение прав доступа (Owner, Editor, Viewer);
- постраничный вывод данных.

## Особенности проекта

- разграничение прав доступа пользователей;
- хранение истории изменения статусов;
- выполнение автоматической проверки пользовательских историй по критериям INVEST;
- сохранение истории выполненных проверок;
- динамическое обновление пользовательского интерфейса без перезагрузки страниц;
- реализация клиентской части на чистом JavaScript без использования фреймворков.

## Архитектура

Приложение построено по многослойной архитектуре:

Controller
↓
Service
↓
Repository
↓
PostgreSQL

Клиентская часть взаимодействует с сервером посредством REST API.

## REST API

| Метод | Endpoint | Назначение |
|-------|----------|------------|
| POST | /boards | Создание доски |
| GET | /boards | Получение списка досок |
| POST | /boards/{id}/stories | Создание истории |
| PUT | /stories/{id} | Редактирование истории |
| DELETE | /stories/{id} | Удаление истории |
| POST | /api/invest/story/{id} | Выполнение INVEST-проверки |
